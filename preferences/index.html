Addon Preferences Configuration

Welcome to the Scene Light Manager (SLM) Preferences documentation. The addon's preferences are divided into five organized sections inside Blender's Addons panel (Edit > Preferences > Add-ons > Scene Light Manager). Customize these settings to adapt the tool to your lighting pipeline.

── 1. General & Sync Settings ──

These preferences control the integration level between SLM and Blender, configuration paths, and shader preview render loops.

User Interface & Selection Sync

  • Show Debug Messages show_debug_messages:

    Prints system logging messages to Blender's console. Keep this disabled unless troubleshooting to avoid cluttering console logs.

  • Sync Selection sync_selection:

    Bidirectionally links selections in the SLM list to viewport selection. Selecting a light in the list selects its 3D object, and vice-versa.

  • Fallback to World on Deselect sync_world_fallback:

    Automatically highlights the active scene World settings in the SLM list if viewport selection is cleared, providing quick access to HDRI angles.

  • Sync Collection Selection sync_collection_selection:

    Synchronizes selection of light rig collections or parent groups in the list to highlight and select them in Blender's native Outliner.

Render & Visibility Sync

  • Show Selected Light in Camera Render temp_visible_camera_on_select:

    Temporarily forces the selected emitter's physical geometry to show up in test renders, allowing you to preview softbox scales and textures during active Cycles previews.

  • Sync Render Visibility sync_visibility_drivers:

    Binds viewport visibility (Eye icon) directly to render visibility (Camera icon). Resolves the common issue where hidden viewport objects still render in final outputs.

[TIP] Sync Drivers: Enabling "Sync Render Visibility" creates Blender drivers linking visibility properties. Moving or rendering scene lights will strictly adhere to viewport statuses.

Shader Preview & Environment

  • Shader Preview Auto Refresh Interval preview_refresh_interval:

    The timer duration (in seconds) used to debounce and trigger the persistent scene preview render after shader properties are altered.

  • Preview Render Engine preview_render_engine:

    The internal renderer used to build node thumbnails (EEVEE vs Cycles). Cycles is highly recommended for stable asynchronous processing.

  • Cycles Preview Device preview_render_device:

    Specifies device allocation (CPU or GPU Compute) for Cycles thumbnail rendering loops.

  • HDRI Folder Path k_tools_hdri_folder:

    The target folder containing environment maps. SLM scans this directory for .exr, .hdr, and image textures to index in the environment panel.

Sidebar Tab Mode

  • Tab Mode category_mode:

    Controls where the N-Panel sidebar renders.

    Solo Tab (K-Tools) Default cleaner setup. Renders in a designated 'K-Tools' category.
    Scene Properties Appends panels to the native properties category.

── 2. Light List & Component Detection ──

Settings under this category customize the hierarchy layout columns, isolation parameters, and tag keyword lists.

List Display Columns

Toggle columns to streamline UI footprints:

Selectability Toggles show_hide_select
Viewport Eye Icons show_hide_viewport
Render Camera Icons show_hide_render
Exposure Locks show_hide_exposure
Light Group tags show_hide_lightgroup
Linking Columns (LL / SL) show_hide_light_linking

Solo Mode Viewport Isolation

  • Isolate Current Collection Only isolate_current_group_only:

    When turning Solo mode on, only lights within the active collection are muted, leaving external collection rigs untouched.

  • Disable World Nodes (Mute HDRI) isolate_disable_world_nodes:

    Toggles off environment backgrounds while Soloing lights to analyze precise shadowing shapes in total darkness.

Keyword Scanners (Component Detection)

  • List Mesh Lights enable_mesh_lights:

    Enables background scene scans to trace mesh objects tagged as emitters. De-select in heavy architectural scenes to avoid depsgraph delays.

  • Search Keywords:

    Comma-separated suffix naming triggers used to catch custom components during automatic scene parsing:

    Mesh Lights: glow,emit,led
    Bouncers: bouncer,reflector
    Blockers: blocker,flag,gobo

── 3. Viewport Highlights & Gizmos ──

Adjust the visual representations of light properties overlayed in the 3D View.

GPU Outline Styles

  • Highlight Linked Objects enable_gpu_highlights:

    Renders colored overlays around objects bound to the active light via Light/Shadow linking.

  • Highlights Customization:

    Set modes (Silhouette, Wireframe, or Both), colors, outline widths, and fill transparencies:

    Receivers Color Highlights for Light Linking receivers (Default: Light Blue).
    Blockers Color Highlights for Shadow Linking blockers (Default: Orange/Amber).

Interactive Viewport Gizmo Layout

  • Enable Viewport Gizmos enable_viewport_gizmos:

    Toggles draw loops of quick-buttons overlayed adjacent to active light sources.

  • Offsets & Styling:

    Tweak horizontal (X) and vertical (Y) offsets, button scales, row item counts, background colors, and hovered highlighting scales.

  • Value Overlay Position gizmo_overlay_position:

    Determines where floating slider readouts display: following the mouse cursor or anchored below the viewport buttons.

── 4. Library & Keybindings ──

  • Auto-Assign Softbox auto_assign_softbox:

    Automatically links the custom Softbox shader node group to any newly created Area Light, bypassing manual node additions.

  • Keybindings Customization:

    Tweak global shortcut parameters:

    Operator Default Shortcut Description
    k_tools.quick_popup Y Floating popup properties card.
    k_tools.rotate_hdri Ctrl + Alt + RMB (Drag) Modal Z-axis rotation of environments.
    k_tools.light_at_point Not Set Interact/project light coordinate to mesh point.
